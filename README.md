WanderWay Travels 🌍

Explore the World. Make Memories.

WanderWay Travels is a modern, responsive travel website created to showcase beautiful destinations and provide an engaging trip-planning experience.

This project demonstrates my front-end web development skills using HTML, CSS, and JavaScript.

✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern navigation bar with a mobile menu
- Attractive hero section with travel imagery
- Destination cards with hover animations
- Interactive destination filters for nature, beaches, and luxury
- Clickable destination cards that select a destination in the trip form
- Trip planning form with input validation
- Smooth scrolling and CSS animations
- Clean, organized front-end code

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, responsive layouts, and animations
- JavaScript — Interactive features and form validation

🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
5. Explore the destination filters, mobile navigation, and trip planning form.

 📌 Project Note

WanderWay Travels is a front-end portfolio project. The trip planning form demonstrates client-side interaction only; it does not submit real bookings or send enquiries to a travel agency.

The destination images are loaded from Unsplash and require an internet connection.
